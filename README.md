# Dermatopetrio — Demonstração

Site demonstrativo em português do Brasil, inglês dos EUA e espanhol da Espanha. Publicação pelo GitHub Pages, no mesmo esquema do portal Cesamar.

Inclui artigos educativos, apresentação da Dra. Luana, fotos, avaliações e PDFs para baixar. Dados profissionais pendentes e materiais clínicos aguardam validação da clínica.

Abra `index.html` para a demonstração. Os PDFs devem permanecer na mesma pasta para que os downloads funcionem.
